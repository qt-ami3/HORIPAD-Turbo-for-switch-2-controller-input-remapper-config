# Usage

To use, you will need https://github.com/sezanzeb/input-remapper, see download instructions on their repo.

1. Open input input-remapper, look for something like "HORI CO.,LTD. HORIPAD O"

2. Make a config, Dont bother configuring it for now.

3. close input-remapper.

4. Go to /home/your_user_name/.config/input-remapper-2/presets/HORI CO.,LTD. HORIPAD O and copy the contents of the included json into your config.

5. Check to see the config within input-remapper has updated after saving the changes to the file.

6. Open a terminal and enter; ```input-remapper-control --command autoload```
